# My Cards Project

 A simple interactive web application for managing a collection of cards.

 
 # How to Run
🚀  [Посмотреть проект вживую (Live Demo)](https://5555nika.github.io/my-cards-project/) 


 ## Features

 - Add new cards with a title, image path, and description.
 - Delete existing cards from the list.
 - Toggle the  'important' status of each card to hightlight it.

   ## Technologies
   
   - JavaScript
   - TypeScript
